## 2. 주요 화면 요소 명세

### 2.1 상단 액션 바 (Header Action Bar)
- **브랜드/식별 배지 (`[✦ PROFILE]`)**:
  - 현재 화면이 프로필 페이지임을 나타내는 파스텔 민트색 태그 (`bg-[#A7F3D0]`).
  - 2px 블랙 테두리와 2px 하드 섀도우 적용.
- **공유 버튼 (`[ ↗ 공유 ]`)**:
  - 방문자가 크리에이터의 프로필 주소를 쉽게 복사할 수 있는 기능.
  - 클릭 시 `navigator.clipboard.writeText`를 통해 현재 브라우저 URL 복사.
  - 복사 완료 시 2초간 `[✓ 복사 완료!]` 문구 및 에메랄드 색상으로 토글 피드백 제공.

### 2.2 프로필 정보 섹션 (Profile Information)
- **프로필 아바타 (Profile Avatar)**:
  - 원형(w-24 h-24) 레이아웃, 두꺼운 3px 검은색 테두리 및 4px 하드 섀도우.
  - 우측 하단에 활동 상태를 나타내는 그린 인디케이터(🟢) 배치.
- **닉네임 (Nickname)**:
  - 고대비 블랙 컬러의 굵은 텍스트 (Bold 24px~28px).
- **역할/지역 배지 (Role/Location Badges)**:
  - 크리에이터의 직무/활동 분야 및 활동 지역(예: 개발자, Seoul, KR 등)을 나타내는 소형 배지.
- **한 줄 소개 (Bio)**:
  - 최대 2~3줄의 간결한 자기소개 문구.
- **키워드/기술 스택 칩스 (Keyword Chips)**:
  - 주요 관심사, 스택 또는 운영 채널 태그를 파스텔톤 배경의 칩 형태로 노출.

### 2.3 세로형 링크 카드 목록 (Link Cards)
- **정렬 순서**:
  - 소유자가 관리자 화면(`/admin`)에서 **마지막으로 저장한 순서**와 100% 동일하게 위에서 아래로 세로 나열.
- **카드 구성 요소**:
  1. **좌측 아이콘 박스 (40x40px)**: 깃허브, 이메일, 웹사이트, 유튜브 등 각 채널을 상징하는 아이콘 노출 (호버 시 미세 회전 효과).
  2. **링크 제목 및 배지**: 링크의 주요 명칭과 카테고리 태그.
  3. **보조 설명(Description)**: 방문자가 어떤 링크인지 바로 파악할 수 있는 1줄 설명.
  4. **우측 외부 링크 아이콘 (`[↗]`)**: 외부 새 창 이동을 명확히 인지시키는 화살표 아이콘.
- **클릭 인터랙션**:
  - 클릭 시 대상 사이트가 새 탭(`target="_blank"`, `rel="noopener noreferrer"`)에서 열림.
  - 마우스 호버 시 살짝 떠오르고(`hover:-translate-y-0.5`), 클릭 시 버튼이 꾹 눌리는(`active:translate-y-1`) 네오브루탈리즘 물리 효과 적용.

### 2.4 하단 푸터 (Footer)
- 저작권 문구 및 서비스 크레딧 표기.
- 2px 상단 구분선으로 링크 카드 영역과 분리.

## 3. UI/UX 디자인 테마 명세 (네오브루탈리즘)

- **배경색**: 생동감 있는 파스텔 옐로우 (`bg-[#FEF08A]`)
- **컨테이너**: 깔끔한 흰색 바탕 (`bg-white`)
- **외곽선**: 번짐 없는 선명한 2px~3px 검은색 테두리 (`border-black`)
- **그림자**: 블러/그라데이션이 전혀 없는 단색 블랙 하드 드롭 섀도우 (`shadow-[..._#000]`)
- **반응형 규격**: 모바일 환경을 우선 고려하여 기본 너비 100%, 최대 너비 `max-w-[420px]`로 중앙 정렬
